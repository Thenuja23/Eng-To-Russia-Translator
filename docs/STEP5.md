# Step 5 - Learning v1: alphabet chart, trap-letter drills, flashcards, practice-sheet PDF

## Goal
Basic learning module - alphabet chart (33 letters, upper/lower, block beside cursive), trap-letter drills (т looks like m, д like g, и like u, п like n, г like r, б like 6), flashcards with spaced repetition, printable practice sheets with slanted school guidelines.

## Files
- frontend/src/components/AlphabetChart.jsx
- frontend/src/components/TrapLetterDrills.jsx
- frontend/src/components/Flashcards.jsx
- frontend/src/components/PracticeSheet.jsx
- backend/app/services/learning/alphabet.py (optional)
- docs/learning/alphabet.json

## Done when
- Alphabet chart displays block and cursive forms
- Trap letters identified and practiced
- Flashcard UI with basic SRS states
- Practice sheet renders for printing
